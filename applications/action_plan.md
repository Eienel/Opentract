# Application Action Plan
**Profile:** Africa-based student / 0-1 years professional, strong ML portfolio (FlagOS Qwen3-4B ICL pipeline).

**Goal:** Get to first paying gig in the shortest realistic time (2-4 weeks), then build steady income.

---

## Apply in this order (top → bottom = highest expected $/effort first)

### Tier 1 — apply tonight

#### 1. Mercor (`mercor.com/apply`) — **first priority**
- **Why:** Explicitly weights portfolio + technical interview over credentials. Final-year/junior with a real LLM project is exactly their underserved profile. Accepts every major African country. Pays weekly via Wise.
- **Realistic outcome for your profile:** $15-30/hr entry, scaling to $40+ once you have 1-2 project reviews.
- **Process:** Resume → AI interview (60-90 min, behavioral + technical) → coding/portfolio review → project match.
- **Time to first cash:** 7-21 days.
- **Use:** `applications/mercor_profile.md` (drafted next, needs your details).

#### 2. Outlier (`outlier.ai/expert/apply`)
- **Why:** AI training / RLHF / code-review work. Pays $20-35/hr for code tasks at junior level. Stronger in NG / KE / ZA than other African regions.
- **Process:** Resume + sample test (1-2 hr coding/reasoning) → ID verification → project assignment.
- **Time to first cash:** 5-14 days.
- **Payout:** PayPal preferred, Airwallex secondary. **NOTE:** Confirm your country supports Airwallex if you don't have PayPal.

#### 3. Surge AI (`surgehq.ai/become-a-surger`)
- **Why:** Lower-friction AI training tasks. Smaller payouts but faster to first task.
- **Process:** Sign-up → short qualifier → tasks within 3-7 days.
- **Payout:** Bank transfer / PayPal.

### Tier 2 — apply this week

#### 4. Andela (`andela.com/talent`)
- **Why:** Africa-focused, brand-name on your CV, but their model shifted toward full-time placements (vs hourly gigs). Slower onboarding (2-4 weeks) but higher per-engagement pay if matched.
- **Process:** Profile + technical assessment + interviews.
- **Best for:** Once you have a few months under your belt; apply now to start the clock.

#### 5. Toptal (`toptal.com/talent/apply`)
- **Why:** Highest pay ($30-60/hr at junior tier) but **brutal screening (top 3%)**. Realistic for a strong portfolio if you can pass live coding + project interview.
- **Process:** Language proficiency → online screening → live algorithm interview → test project (1-2 weeks).
- **Time to first cash:** 3-8 weeks.

### Tier 3 — secondary backup

#### 6. Toloka (`toloka.ai/tasks`) — fallback only
- Microtask labeling. $1-4 per 2 hours. Use only if all above stall and you need any income.
